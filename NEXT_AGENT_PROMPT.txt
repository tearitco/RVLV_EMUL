## 🏗️ LONG-TERM VISION (Bootstrap from NAND)

```
NAND (HDLb0) → RV1 → RV2 → RV4 → RV8 → RV16 → RV32I (HDLb0 design)
                                    ↓
                              rvemu (execution layer)
                                    ↓
                              prisc+x VM (software bridge)
                                    ↓
                              Self-hosting C compiler (written IN prisc+x)
                                    ↓
                              Linux kernel (compiled BY bootstrapped compiler)
```

**You do NOT need to write a compiler/kernel in C now.** The bootstrap compiler will be written IN prisc+x assembly, then compile itself. rvemu is the execution layer; HDLb0 is for verification.
