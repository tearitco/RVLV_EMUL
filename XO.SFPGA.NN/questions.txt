Q2: Bitstream format - resolved vs symbolic
The HDL0 source files use named signals (e.g. lut0.out, in0). The bitstream_entry_t
struct has physical addressing fields (src_clb, src_lut, dst_clb, dst_lut). Should the
PNR produce a fully-resolved bitstream (wire indices), or keep symbolic names in the
bitstream and resolve at load time?

Proceeding with fully-resolved bitstream (post-PNR physical wire indices). The PNR
resolves HDL0 symbol names to wire indices. If the parent agent prefers a different
approach, this is the main integration point that would need revision.
