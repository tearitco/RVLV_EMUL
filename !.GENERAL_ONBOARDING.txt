--------------------------------------------------------------------------------
1. WHAT IS RVLV_EMUL
--------------------------------------------------------------------------------

RVLV_EMUL is an in-house project building a self-hosting RISC-V software stack
from the ground up. It includes:

- rvemu: A complete RISC-V RV64 emulator (ISA, MMU, SBI, PCIe, virtio, CLINT,
  PLIC, UART, etc.) - src/
- prisc+x: A VM that runs .pal assembly scripts - 0.hdl0+prisc-bootstrap/
- prisc_bare: Bare-metal prisc+x VM for RISC-V hardware - src/prisc_bare.c
- Buildroot Linux: Full Linux userspace running on rvemu
- Minimal Linux kernel config (kernel/.config)
- Bootstrap toolchain: musl cross-compiled for RISC-V, buildroot toolchain

The end goal: A fully bootstrapped C compiler written in .pal that can
compile its own source, producing a self-hosting stack.

--------------------------------------------------------------------------------
2. KEY COMMANDS
--------------------------------------------------------------------------------

Build rvemu:
    cd RVLV_EMUL && ./build.sh

Run rvemu self-test:
    ./build/main --selftest

Run prisc+x (Linux mode):
    gcc -o prisc_x 0.hdl0+prisc-bootstrap/prisc+x.c && ./prisc_x test.pal

Run prisc+bare (on rvemu):
    buildroot/output/host/bin/riscv64-buildroot-linux-gnu-gcc \
      -nostdlib -static -mcmodel=medany -T bare.ld \
      -o prisc_x_bare.elf src/prisc_bare.c
    ./build/main -k prisc_x_bare.elf --max-inst 10000000

Quick reference: see CHECKLIST.md for the full task status

Key details for the assembler:
- Must emit ELF64-riscv (little-endian, RV64I/ADDI/JAL/BEQ/LW/SW)
- Two-pass: pass 1 = labels, pass 2 = codegen
- Output to file (the existing string-write primitive can't emit NUL bytes
  safely, so you may need a raw-file-write syscall)
- Test with: readelf, objdump, and running on ./build/main
